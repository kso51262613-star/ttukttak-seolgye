AI 도움 (선택)

클로드 API 키가 있으면 📷 사진·영상으로 설계(1회 약 200~400원)와, 말로 설계에서 템플릿을 못 찾았을 때 AI 설계(1회 약 100~300원)를 쓸 수 있어요. 키는 이 기기에만 저장되고, 내보내기 파일에도 들어가지 않아요.

키 만드는 법 (처음 한 번, 10분쯤)
  1. platform.claude.com 에 들어가서 가입해요. 새로 가입하면 시험용 무료 크레딧이 조금 생겨요.
  2. Settings(설정) 안의 Billing(결제)에서 카드를 등록하고 크레딧을 충전해요. 처음엔 5달러(약 7천 원)면 충분해요.
  3. 같은 Billing 화면의 Spend limits(사용 한도)에서 Set limit(한도 정하기)를 눌러 월 한도를 걸어요. 예: 10달러. 한도를 넘으면 더 안 써져서 안전해요.
  4. Settings 안의 API keys 에서 Create key(키 만들기)를 눌러요. 이름은 "뚝딱설계 폰"처럼 기기마다 따로 지어요.
  5. sk-ant- 로 시작하는 키는 만들 때 한 번만 보여요. 바로 복사해서 위 칸에 붙여 넣고 "키 확인"을 눌러요.
  6. "키가 맞아요"가 나오면 저장을 눌러요.

키는 비밀번호와 같아요. 카톡이나 문자로 보내지 마세요. 폰과 PC에 키를 따로 만들어 두면, 폰을 잃어버렸을 때 폰 키만 지우면 돼요. 새어 나간 것 같으면 API keys 화면에서 그 키를 지우고 새로 만드세요.
